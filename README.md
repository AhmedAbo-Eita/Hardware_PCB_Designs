# Hardware PCB Designs Portfolio

Welcome to my **Hardware PCB Designs** repository!  
This repo showcases a collection of my **printed circuit board (PCB) designs**, created for various applications including motor control, embedded systems, IoT boards, and power electronics. Each project includes schematic files, PCB layouts, and supporting documentation (mostly developed with **KiCad**).

📍 Repo link: https://github.com/AhmedAbo-Eita/Hardware_PCB_Designs
